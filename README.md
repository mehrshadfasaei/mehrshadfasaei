# مهرشاد فسائی

مهندس شبکه‌ای که روی زیرساخت، VoIP و پشتیبانی IT کار می‌کنه — دانشجوی علوم کامپیوتر، دانشگاه آزاد اسلامی تهران مرکز.

فعلاً کارشناس فنی VoIP در **هاوش** هستم؛ قبل‌ترش هم IT Help Desk در **پژوهشگاه دانش‌های بنیادی** بودم.

---

**در حال حاضر روی این‌ها کار می‌کنم:**
- تنظیم و پشتیبانی سیستم‌های VoIP (Avaya)
- مدیریت شبکه با Mikrotik، Active Directory، DNS/DHCP
- تقویت مهارت‌های اسکریپت‌نویسی (PowerShell) برای اتوماسیون کارهای تکراری IT

**دنبال چی هستم:**
فرصت‌های کارشناس شبکه / VoIP / IT Support که بتونم عمیق‌تر روی زیرساخت کار کنم.

---

### استک اصلی

`Mikrotik` `Active Directory` `DNS` `DHCP` `VLAN` `VoIP Avaya` `Windows Server` `PowerShell` `VMware`
